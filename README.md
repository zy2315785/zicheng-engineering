# 子城联合工程部 · 工程知识助手

品牌色 #631014 / #C9BC9C / #604C3F。11个项目入口，瑞邦国际大厦与火炬汽车电子智能工厂两个项目已接入。

## 启动与迁移
在 AI 文件夹双击“启动工程助手.cmd”。已包含 Windows x64 的 Node.js 与 Python 运行环境，不需要另装软件。
启动时同步已接入项目目录；“更新项目资料.cmd”可以单独更新索引，“停止工程助手.cmd”停止本机服务。
整体复制 AI 文件夹可迁移；首次在新电脑运行时，打开网页左下角设置按钮“云端连接与模型设置”，配置各自的模型和 ima 凭证，并连接百度网盘。
运行地址默认 http://127.0.0.1:4173，端口占用时自动使用4174–4202。本机服务只监听回环地址。

## 问答与文件来源
每次提问先检索 ima“子城”知识库内当前项目文件夹，再结合当前项目本地镜像。
首次查询先由当前配置的模型阅读真实的 ima 项目文件目录，按问题含义选择最多6份候选并生成短查询词。随后执行关键词查询，并探测选中文件的真实文件名，避免把“开工日期”这类字段问题直接当作文件名。模型选材、目录核对与搜索命中分别记录，目录候选不作为正文证据。
本地检索线索必须在当前项目的 ima 目录内按路径或唯一文件名确认；本地独有、浏览器导入及其他项目文件不会被计为云端资料。模糊搜索命中过多时优先保留语义选中的文件。临时网络故障、下游错误和限流最多尝试3次，鉴权失败直接报错。
DeepSeek 使用 deepseek-flash、思考模式、高强度，最多6轮工具调用，保留工具轮次所需的推理字段。
网页显示检索、打开原文等步骤与简洁的文件位置，不再显示大段原文详情卡片。来源按文件合并，保留全部引用编号和页码/行号，路径作为普通文字，仅提供“下载原件”。工程资料库与常用资料的文件入口也直接下载原件，不再打开网盘网页。
下载通过本机后台的已授权百度连接完成，网页不显示密钥或下载令牌；未连接时提示配置。浏览器临时导入的文本没有云端原件，不生成虚假下载入口。
页面包含建筑轮廓绘制、漂浮光点、缓慢光线、滚动入场、数字递增、鼠标跟随柔光、回答分段入场、悬停反馈和问答等待动效；遵循系统的“减少动态效果”设置。
模型可以换词检索、打开文件、按PDF页码继续读取、定位关键词；扫描页按需尝试本机 OCR。
读取原文优先使用同路径本地镜像；本地不存在时从百度网盘取得原件。所有“下载原件”按钮均走百度网盘 /AI 下当前项目目录。
ima 失败时明确显示未完成，不会声称成功检索。断网或未配置模型时保留本地关键词搜索与原文摘录。

## 两个项目的映射
projects.json 是项目清单。folder 为 AI 文件夹下的本地目录，imaFolder 为 ima“子城”下的项目目录，baiduFolder 为百度网盘 /AI 下的项目目录。
名称中的全角/半角括号会规范化比较。出现多份同名文件时需要提供相对路径，不能随意选择。
项目切换同时限制本地检索、ima 文件范围和百度下载目录；尚未接入的项目不能调用其他项目的资料。

## 配置
模型：.local/api-config.json，或 ZC_API_KEY / ZC_API_BASE / ZC_API_MODEL 环境变量。
云端：.local/cloud-config.json，ima 凭证也可以通过 IMA_OPENAPI_CLIENTID / IMA_OPENAPI_APIKEY 环境变量提供。
百度的 access_token、refresh_token 只保存在本机后台，正常使用时自动刷新。
以上配置均在 zicheng-engineering/.local 内，不进入Git、静态网站发布包或默认便携分发包。经打包者明确要求，使用 --include-credentials 可另行生成携带当前 DeepSeek、ima、百度授权的“已配置内部试用版”；它包含真实凭证，按随包使用说明分发和停用。
网页“云端连接”可修改凭证；已保存的密钥输入框留空表示保留，浏览器不会回显密钥。

## 资料同步与解析范围
每次启动按项目扫描新增、删除、修改的文件，失效的本地历史摘录会被移除。
支持 DOCX 正文与表格、XLSX 缓存值、PDF 文本、TXT/MD/CSV。索引默认每个PDF前24页、每张工作表前800行，标注部分解析。
Agent 按需读原件时，每次可翻阅4页PDF并尝试OCR；表格按需读至2000行，原文有范围限制时会说明。
旧DOC、CAD、压缩包等以目录为主，不能把目录存在当成已读懂正文。技术图纸尺寸与专业结论应核对原件。
身份证、公章、通讯录等排除规则延续既有设置，解析文本做号码规则遮蔽。这不是生产系统的完整权限或脱敏方案。
进度回答区分“计划口径”和实际完成记录，遇到版本冲突应说明依据，不能只凭修改时间断定版本最新。

## 检查与维护
从 AI 文件夹运行：
runtime\node\node.exe --test zicheng-engineering\tests\*.test.mjs
runtime\python\python.exe -I -B zicheng-engineering\scripts\verify-portable.py

scripts/package-portable.py --check-only 检查分发清单；不带参数时生成便携zip，保留两个项目全部原件，排除密钥、会话配置、日志、Git和测试副本。
scripts/package-portable.py --include-credentials 生成已配置内部试用包，明确携带三项连接及百度刷新令牌，排除登录会话、运行进程状态与测试副本。scripts/verify-configured-package.py <zip路径> --live 可在新路径和隔离环境中验证真实压缩包。
不要删除 runtime：它是双击启动、文件解析与OCR所需的运行环境。
本地完整问答后台与线上私有静态预览相互独立。静态站点不会读取这台电脑的密钥；后续正式上云需要单独部署后台与配置服务器凭证。
